# 🐍 Python Practice Programs

Welcome to my **Python Practice Repository!**

This repository contains a collection of Python programs created as part of my Python learning and practice journey. These programs cover different Python concepts, including conditional statements, loops, functions, file handling, mathematical operations, GUI development, and socket programming.

The main purpose of this repository is to improve my Python programming skills through practical coding exercises.

## Programs Included

This repository currently contains 12 Python programs:

| No. | Program | Description |
|---|---|---|
| 01 | Income Tax Calculator | Calculates estimated income tax using illustrative tax slabs. |
| 02 | Investment Calculator | Computes investment future value and interest using compound interest. |
| 03 | Square Root Calculator | Calculates both square roots of a number using the `cmath` module. |
| 04 | Flesch Readability Calculator | Calculates the Flesch Reading Ease score and estimated grade level of a text file. |
| 05 | Random Sentence Generator | Generates random sentences using predefined subjects, verbs, and objects. |
| 06 | ELIZA Chatbot | Simulates a simple nondirective psychotherapist using keyword-based responses. |
| 07 | System Information | Displays operating system, disk usage, and current directory information. |
| 08 | Sine Curve Visualization | Draws sine curves for different angular ranges using Python Turtle. |
| 09 | Craps Game | Simulates the dice game Craps using random number generation. |
| 10 | Console ATM Simulation | Simulates ATM operations such as balance checking, deposits, and withdrawals. |
| 11 | GUI ATM Application | Creates a graphical ATM interface using Tkinter. |
| 12 | Two-User Chat Room | Implements a basic client-server chat application using sockets and threading. |
